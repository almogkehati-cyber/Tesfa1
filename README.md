# Tesfa  – Litepaper & Open Source Protocol

## 1. Overview & Vision
**Tesfa ** is a decentralized, open-source protocol designed to enable community-based Universal Basic Income (UBI) and peer-to-peer resource sharing.

The system operates strictly through automated smart contracts without central authority:
* **Fully Decentralized:** Governed entirely by code on the blockchain.
* **No Admin Keys:** Developers and founders have no special permissions, backdoors, or administrative controls.
* **Public Good:** Open-source, transparent, and free for anyone to use.

---

## 2. Token Mechanics
* **Fixed Supply:** Total maximum supply capped at **30,000,000 (30 Million)** Tesfa tokens.
* **Community UBI:** Equal periodic distribution to verified community participants.
* **Demurrage Mechanism:** Inactive tokens experience a gradual algorithmic decay to encourage circulation and discourage hoarding.
* **Lock & Unlock:** A portion of tokens is locked in smart contracts and released systematically according to a fixed time schedule.

---

## 3. Architecture
* **Blockchain Network:** Deployed on an EVM-compatible network (e.g., Polygon) for fast, low-cost transactions.
* **Decentralized Storage:** Application interfaces hosted on IPFS / Arweave.
* **Authentication:** Direct connection via non-custodial wallets (WalletConnect / MetaMask). No personal data required.

---

## 4. Client Applications
The protocol supports two mobile client applications:
1. **Tesfa Wallet:** Interface for viewing balances, lockup countdowns, claiming UBI, and checking demurrage metrics.
2. **Tesfa Marketplace:** Peer-to-peer listing platform for trading goods and services directly using Tesfa tokens.

---

## 5. Disclaimer
* **Software Only:** Tesfa is open-source computer software. It is not a bank, financial institution, or payment provider.
* **No Security Offering:** Tokens are not offered for sale and do not represent equity, investment contracts, or financial returns.
